## Download

- **Windows** (Intel/AMD and ARM): `USBeam-Setup-@VERSION@.exe`
- **Linux** (most distributions with systemd): `USBeam-@VERSION@-x86_64.AppImage`

Already have USBeam? Open it → gear icon → **Check for updates**. Pairings and settings are kept.

## Installing

**Windows**

1. Download `USBeam-Setup-@VERSION@.exe` below.
2. Double-click it and follow the steps. Windows asks for permission: click **Yes**.
3. If the installer asks you to restart Windows (only the first time, for the USB driver), restart.

**Linux (AppImage)**: no terminal needed.

1. Download `USBeam-@VERSION@-x86_64.AppImage` below.
2. Right-click the file → **Properties** → **Permissions**, and tick **Allow executing file as
   program** (in some file managers: **Is executable**).
3. Double-click the file, click **Install**, and enter your password.

USBeam then starts with your computer (you can turn that off in the gear menu), appears in your
application or Start menu, and can be uninstalled from the gear menu.

## Pairing two PCs

1. On both PCs, open USBeam → gear icon → **Pair a PC**.
2. On one of them, pick the other PC and click **Pair**.
3. Type the 6-digit code the other PC shows.
